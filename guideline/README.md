# App Guidelines — E.O.C Church

Richtlijnen voor de app (Android + iOS).

**Kernprincipes:**
- Heilige, rustige en professionele uitstraling (parchment / warm ivoor achtergrond, diep bordeaux/wijnrood accenten, warm goud).
- Soepel en prettig in gebruik.
- Geen intro-video of opening scene.
- Geschikt voor Eastern Orthodox, Oriental Orthodox en Catholic content.
