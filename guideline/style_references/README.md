# AGAPE — Style References & Prompt

This folder contains visual style references and a ready-to-use prompt for Claude (or other AI) when building the AGAPE app.

## How to use
1. Copy the content of `claude_prompt.md`
2. Upload the images below (or let Claude view this file) to Claude
3. Paste the prompt

## Important
The images are **style and color references only**.  
Do **not** copy their layouts or bottom navigation.

The correct bottom navigation is always:  
**Home → Bible → Prayer → Me**
