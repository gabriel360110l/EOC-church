This folder contains visual style references and a ready-to-use prompt for Claude (or other AI) when building the AGAPE app.

## How to use
1. Copy the content of `claude_prompt.md`
2. Upload the images in this folder to Claude
3. Paste the prompt

## Important
The images are **style and color references only**. Do not copy their layouts or bottom navigation.
