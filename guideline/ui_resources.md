# UI & Design Resources (Android + iOS)

## Officiële richtlijnen
- **Android**: [Material Design 3](https://m3.material.io/)
- **iOS**: [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)

## Iconen
- Byzantine / Orthodox iconen (public domain of vrij te gebruiken): zie `shared/byzantine_icons.md` in deze repo.
- Systeemiconen: Material Symbols (Android) en SF Symbols (iOS).

## Typografie
- Google Fonts (gratis en open): Crimson Pro, Lora, EB Garamond voor serif; Inter of Roboto voor UI.
- Link: https://fonts.google.com/

## Open-source inspiratie
- Zoek op GitHub naar “orthodox bible app”, “prayer app compose” of “flutter bible” voor voorbeelden van navigatie en lezers.
- Flutter (cross-platform): https://github.com/flutter/flutter — officiële repo + design-documentatie.
- React Native: https://github.com/facebook/react-native
