# Eastern Orthodox — Prayers & Horologion

Sources for the daily prayer cycle (Hours) and common prayers used in the Eastern Orthodox Church.

---

## mdws-org / orthodoxprayers
- **What it is:** Complete open-source Orthodox prayer book.
- **What you get:** Morning and Evening Prayers, the Small Hours, Compline, Canons, and the 20 Kathismata of the Psalter.
- **Link:** https://github.com/mdws-org/orthodoxprayers
- **Best for:** Full Horologion texts in English.

---

## typiconman / ponomar
- **What it is:** Very large multilingual database of Orthodox liturgical texts.
- **What you get:** Fixed and variable services in English, Greek, Church Slavonic, Arabic, and more (XML format).
- **Link:** https://github.com/typiconman/ponomar
- **Best for:** Advanced liturgical texts and multi-language support. Note: the repository is large.

---

## Orthocal API (readings & propers)
- **What it is:** Free API that returns the daily readings, saints, fasting rule, and hymns for any date.
- **What you get:** Epistle, Gospel, saints of the day, troparia, fasting information.
- **Endpoints:**
  - Gregorian: `https://orthocal.info/api/gregorian/YYYY/MM/DD/`
  - Julian: `https://orthocal.info/api/julian/YYYY/MM/DD/`
  - Today: `https://orthocal.info/api/gregorian/`
- **Best for:** Daily content in an app.

---

## brianglass / orthocal-service
- **What it is:** The source code and database behind the Orthocal API.
- **What you get:** Full offline copy of the readings and saints database if you want to host it yourself.
- **Link:** https://github.com/brianglass/orthocal-service
- **Best for:** Self-hosting or deeper customization.
